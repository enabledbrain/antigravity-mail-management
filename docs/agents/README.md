本リポジトリ（`antigravity-mail-management`）は、共通エージェント指示書（`AGENTS.md`）を備えており、各種自律型 AI エージェントと協調して動作します。  
本ドキュメントでは、各 AI エージェント別の設定方法、定期実行の実現方法、および注意点をまとめています。

---

## 1. はじめに
本ツールは **「Docker コンテナ ＋ Python ＋ Meilisearch ＋ Markdown ルール」** で構成されているため、どの AI ツールでも検索・要約・設定変更を実行できます。  
ただし、**「30分ごとの定期実行（自動巡回）」をどのような仕組みで動かすか** において各エージェントの特性に応じた違いがあります。

---

## 2. 各 AI エージェントの対応・機能比較

| AI エージェント | オンデマンド実行・検索 | 定期実行 (30分おき) | API キーの要否 | 特徴・推奨度 |
| :--- | :---: | :---: | :---: | :--- |
| **Google Antigravity** | **◎ 完全対応** | **◎ 内蔵タイマー (`schedule`)** | **不要** (内蔵 AI 利用) | **【推奨】** チャットで指示するだけで定期巡回・停止が完結。 |
| **Claude Code (CLI)** | **○ コマンド対応** | **△ OS スケジューラ併用** | 要または内蔵認証 | ターミナル操作に最適。cron / launchd から呼び出して運用。 |
| **Cursor / Windsurf** | **○ チャット対応** | **△ OS スケジューラ併用** | 要 (設定ファイル) | エディタ内の Composer / Agent から検索・ルール改定が可能。 |
| **GitHub Copilot** | **○ チャット対応** | **△ OS スケジューラ併用** | 要 (設定ファイル) | VS Code 内の Agent モードで対話操作が可能。 |

## 3. Google Antigravity (推奨・完全対応)

Google Antigravity は、エージェント自身がバックグラウンドスケジューラを内包しているため、**最も簡単かつ安全に完全自動化** できます。

### 特徴
- **外部 API キー不要**: Antigravity 内蔵の Gemini モデルを使用するため、Gemini API キーの契約・設定が不要です。
- **会話で定期実行**: OS の cron 設定をいじることなく、チャットで「30分おきにメールチェックして」と指示するだけでバックグラウンド巡回が始まります。

### 運用方法
1. Antigravity で本リポジトリを開きます。
2. チャットで「**定期メール巡回を開始して**」と伝えます（エージェントが自動で `schedule` タスクを登録）。
3. 過去メールの検索も「**先週届いた見積書メールを検索して**」と話しかけるだけで、エージェントが Meilisearch を叩いて回答します。

## 4. Claude Code (CLI)

Anthropic 社が提供するターミナル専用自律型エージェントです。

### 特徴
- ターミナルから `claude` コマンドで対話しながらメール検索やスクリプト改定が可能。
- 現時点ではデスクトップアプリ版との直接的なリアルタイム画面同期機能はありません。

### 定期実行の設定方法（macOS / Linux の場合）
OS の `crontab` を使って定期的に呼び出します：
```bash
# 30分おきに実行する crontab 例
*/30 * * * * cd /path/to/antigravity-mail-management && ./run.sh >> data/cron.log 2>&1
```

## 5. Cursor / Windsurf

次世代 AI エディタ（Cursor や Windsurf）での利用手順です。

### 特徴
- エディタのサイドバー（Composer / Agent チャット）で本リポジトリを開き、指示を出せます。
- 「このルールの要約条件を少し変えて」と伝えると、`rules/summary_rules.md` を直接編集してくれます。

### 定期実行の設定方法
エディタ単体にはバックグラウンドスケジューラ機能がないため、以下のいずれかを利用します：
1. **OS スケジューラ**: Windows の「タスクスケジューラ」または macOS の `launchd` / `cron` で `run.bat` / `run.sh` を定期実行。
2. **常駐ターミナル**: エディタのターミナルで定期ポーリングスクリプトを実行。

---

## 6. GitHub Copilot (VS Code)

VS Code 上で GitHub Copilot Chat (Agent mode) を使用する場合の手順です。

### 特徴
- ターミナルコマンドの実行許可を与えることで、Copilot チャットから `./run.sh --search "..."` などを呼び出してメール確認が可能です。

---

## 7. 注意事項・セキュリティ

1. **クレデンシャルの保護**:
   どの AI ツールを利用する場合でも、`config.json` や `.env`、`data/` 配下の実データを Git にコミットさせないよう注意してください（`.gitignore` で除外済み）。
2. **複数端末での実行**:
   複数端末で実行する場合は、各端末で Thunderbird プロファイルのパスが異なるため、`.env` で各端末に応じたパスを設定してください。
